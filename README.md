# Enquiry Management System

A backend application developed using Java and Spring Boot to manage customer enquiries. The application provides REST APIs to create, retrieve, search, and delete customer enquiries stored in a MySQL database. It also sends an email notification when a new enquiry is submitted.

### Features

* 📩 Create & manage customer enquiries
* 🔍 Search enquiries by different fields
* 🗄️ Store data securely in MySQL
* 📧 Send email notifications
* 🔗 RESTful APIs for easy integration
  
### Technologies Used

  Java | Spring Boot | Spring Data JPA/Hibernate | MySQL | Spring Boot Mail | Maven | REST API

### Run the Project

Configure MySQL in `application.properties`, then run

```bash
mvn spring-boot:run
```

Test the APIs using **Postman**
